# Дашборд АВТОРЕПАР — статичная копия для собственного домена

Это самостоятельная статичная версия дашборда «Дистрибьюторы АВТОРЕПАР»
(исходник: `https://claude.ai/artifact/4o6TQosELF2McVQMCWEq43`), подготовленная
для размещения на твоём собственном домене — тем же способом, что и
персональный сайт (`aservice.duckdns.org`): бесплатный поддомен DuckDNS +
GitHub Pages.

## Что внутри

- `index.html` — вся страница (вёрстка, стили, скрипты и данные по 842
  дистрибьюторам) в одном файле. Ничего собирать не нужно.
- `CNAME` — файл для GitHub Pages с доменом `avtorepar.duckdns.org`
  (можешь поменять на любой другой свободный поддомен в твоей панели
  DuckDNS — тогда просто впиши его сюда вместо этой строки).

## Важное отличие от версии на claude.ai

На claude.ai статусы аутрича («черновик», «отправлено», «ответили» и т.д.)
сохраняются в общую базу и видны всем, у кого есть ссылка — это работает
только на хостинге claude.ai. Здесь, на обычном статичном хостинге, такой
общей базы нет:

- Фильтры, поиск, карточки, модалки с черновиками писем, экспорт в CSV —
  всё работает как обычно, без ограничений.
- Отметка статуса аутрича (выпадающий список в карточке) работает, но
  **только в рамках одной открытой вкладки** — при обновлении страницы или
  у другого человека, открывшего ссылку, статусы не сохраняются и не
  синхронизируются. Страница уже спроектирована так, чтобы тихо
  деградировать до такого режима (ошибок не будет).

Если понадобится вернуть именно общие сохраняемые статусы — это отдельная
задача (нужен настоящий бэкенд, например Firebase/Supabase), не покрыта
этим файлом.

## Как опубликовать (все шаги — на твоей стороне, доступа к твоим аккаунтам у меня нет)

1. **DuckDNS**: зайди в свою панель DuckDNS (тот же аккаунт, что для
   `aservice.duckdns.org` и `sashai.duckdns.org`) и зарегистрируй новый
   поддомен, например `avtorepar` → получится `avtorepar.duckdns.org`.
   Если хочешь другое имя — просто используй его и поправь файл `CNAME`.
2. **Новый репозиторий на GitHub**: создай отдельный репозиторий (например
   `avtorepar-outreach`), залей туда `index.html` и `CNAME` из этой папки
   (в корень репозитория, ветка `main`).
3. **GitHub Pages**: Settings → Pages → Source: `Deploy from a branch`,
   branch `main`, папка `/ (root)`. В поле Custom domain впиши
   `avtorepar.duckdns.org` (GitHub сам подхватит файл `CNAME`, но можно и
   вручную). Сохрани.
4. **DNS в DuckDNS**: укажи для поддомена A-запись на один из IP GitHub
   Pages — `185.199.108.153`, `185.199.109.153`, `185.199.110.153` или
   `185.199.111.153` (любой из четырёх подойдёт).
5. Подожди несколько минут на распространение DNS, затем в том же разделе
   Settings → Pages включи **Enforce HTTPS** (появится, когда сертификат
   будет выпущен — обычно от пары минут до часа).
6. Готово — страница будет открываться по `https://avtorepar.duckdns.org`.

Это полностью бесплатный путь (DuckDNS + GitHub Pages), без покупки
домена и без привязки карты — тот же вариант, что ты уже выбирал для
личного сайта.
